Skyrim Fitting System v1.5.3

주요 변경

  • SexLab P+ v2.12.0의 Skyrim 1.5.97·1.6.1170 패키지에 별도 패치 없는 내장 탈의·재착의 연동을 추가했습니다. 모드 설정·직접 편집+모드 설정은 가상토큰, 바닐라·직접 편집+바닐라는 기존 실제 장비 경로를 유지합니다.
  • 장비·의상·키트에 기본 활성화되는 바디 호환 필터 옵션을 추가했습니다. 불확실한 커스텀 액터는 전체 표시하며 등록 외형 작업대에는 필터를 적용하지 않습니다.
  • 스크롤바 드래그를 놓을 때 목록이 최상단으로 돌아가던 문제와 일시정지 상태의 다음 UI 실행에서 Left/Right 캐릭터 구도가 끝까지 적용되지 않던 문제를 수정했습니다.
  • 거짓 항목이 든 사용자 정의 조건을 다른 조건에서 다시 거짓으로 참조해 저장할 때 게임이 멈추던 문제를 수정했습니다.
  • RaceMenu 구형 NiOverride transform, NiTransform v3 이상, 호환 BodyMorph v4/v5 경로를 버전별로 안전하게 선택하면서 플레이어·NPC·팔로워 및 DAVE·DAV·native 경계를 유지합니다.
  • 피팅 염색 대상에서 UBE의 ArmColli, FeetColli, ButtLegColli 같은 축약 충돌 헬퍼를 제외했습니다.

호환 경계

  • 실제 장비·인벤토리, 등록 외형·조건·잠금·염색 저장, 네 가지 탈의 연동 정책, DD·Pama·Grid·HT2·OAR 및 IED 호환 체인은 변경하지 않았습니다.
  • 런타임 ZIP과 MO2에는 PDB를 넣지 않으며 디버그 심볼은 로컬 빌드 폴더에만 남습니다.
