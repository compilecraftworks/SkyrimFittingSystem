# Skyrim Fitting System v1.3.1 개발 기록

v1.3.1은 정식 배포되지 않은 중간 개발 버전입니다. 직전 정식 배포본은 v1.3.0이며, 아래에서 개발한 내용은 추가 안정화와 함께 모두 v1.4.0에 통합되었습니다. 실제 배포 안내와 최종 변경 내역은 `RELEASE-NOTES-v1.4.0-ko.md`를 기준으로 합니다.

## v1.4.0에 통합된 내용

- Helmet Toggle 2 전용 Papyrus 브리지, 임시 co-save 상태, 작업대 표시 잠금·배너와 선택 패치 소스 제거
- 머리·가발·서클릿을 일반 수동 표시, 조건, 실제 장비 탈의 연동 규칙으로 통합
- 자동 장비 억제를 UI뿐 아니라 native·DAV·DAVE 렌더 외형에도 동일하게 반영
- 기본 특수 이펙트 보호 슬롯에 60번을 포함해 50, 51, 60, 61번으로 정리
- OBody·FHU·SGO를 포함한 RaceMenu BodyMorph 갱신 뒤 해당 액터의 등록 외형만 동기화
- 전역 액터 스캔·주기적 폴링·모드별 전용 이벤트 목록 없이 DAVE·DAV·native 공통 경로 사용
- 실제 장비와 등록 외형에 같은 SOS/TNG 32·49번 최종 판정 적용
- SOS MCM 사용자 선택과 ESP·KID 원본 키워드 보존

이 기록의 기능은 v1.3.1 파일로 설치하지 말고 v1.4.0 본체에서 사용하십시오.
