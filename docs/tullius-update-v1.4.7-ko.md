# Skyrim Fitting System v1.4.7 업데이트

- IED가 Skyrim 커스텀 스킨 재구성의 동일한 장비 순회 호출을 선점한 경우에만 적용되는 호환 처리를 추가했습니다.
- 숨긴 실제 장비가 있는 재구성은 SFS filter visitor를 IED 훅에 전달하지 않고 원본 엔진 호출로 처리한 뒤, IED의 공개 액터별 평가를 지연 요청합니다.
- 요청은 액터별 중복 방지 방식이며 SFS 갱신 상태가 초기화되면 함께 정리됩니다.
- IED 나체/장비 조건 판정, 등록 외형·실제 장비 표시 정책, 외부 모드 탈의 연동의 동작은 바꾸지 않습니다.
- 모드 설정 슬롯 연동, 바닐라 슬롯 자동 연동, 직접 편집, DAVE·DAV·Skyrim native 표시 백엔드는 기존 경로를 유지합니다.
