# Skyrim Fitting System v1.7.4 SE-AE

## 변경 사항

- 실제 장비를 숨기면 바닐라 착용 충돌 검사에서 빠져, 같은 물리 슬롯의 장비를 중복 착용할 수 있던 경로를 수정했습니다.
- 누락된 실제 착용 장비를 기존 엔진 검사에 전달합니다. 슬롯 판정·퀘스트 제한·장비 교체는 계속 스카이림이 처리하며, SFS의 별도 착용/해제 규칙이나 인벤토리·착용 플래그·장비 슬롯값 변경은 추가하지 않습니다.
- 네이티브와 DAV는 같은 엔진 입력 보정을 사용하고, DAVE의 기존 착용 충돌 훅은 보존합니다. 등록 외형의 슬롯 규칙과 렌더 처리는 변경하지 않습니다.
- RaceMenu/NiOverride 연결, 바디모프·하이힐·염색·탈의/재착의·IED·렌더 외형 API는 유지합니다. 인벤토리 메뉴 스캔·주기적 액터 순회·액터/장비 보관 캐시는 추가하지 않았습니다.

## 업데이트 안내

본체 전체 패키지를 설치하고 기존 설정·키트·세이브를 유지하세요. 선행 모드·게임 지원 범위·보조 ESL·스크립트·선택 호환 패치는 그대로입니다. 런타임 패키지에서는 SFSCore.dll만 변경됩니다.

이 수정은 이전 버전에서 이미 중복 착용된 장비를 자동 정리하지 않습니다. 이미 중복된 슬롯은 해당 장비들을 한 번 벗은 뒤 정상적인 교체 착용을 확인하세요.

## 검증 범위

SE/AE 전용 릴리즈 빌드, 회귀 검사 37개와 소스 검사를 통과했습니다. SE 1.5.97·AE 1.6.1170의 메인 메뉴에서 관련 엔진 코드를 읽기 전용으로 확인했습니다. 실제 생산 코드와 x64 훅 검사에서 레지스터·플래그 보존, 액터 소유권, 렌더 데이터 무변경과 물리 슬롯 전환 4,096건을 확인했습니다. 기존 네이티브/DAV/DAVE·RaceMenu 회귀 검사도 통과했습니다.

다른 지원 게임 버전에는 동일한 검증 조건을 둔 보정 경로를 연결했으며, 각각 인게임 실행한 것은 아닙니다. 새 DLL의 실제 게임 내 교체 착용은 아직 미검증입니다. 자동 검사와 메인 메뉴 코드 확인이 모든 모드 조합의 정상 동작을 보장하지는 않습니다.
