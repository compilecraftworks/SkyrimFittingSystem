# Skyrim Fitting System v1.6.9 SE-AE

## 변경 사항

- Grid Inventory Costume 교체 대상을 플레이어의 기본 외형으로 한정했습니다. 조건부 외형 카드, NPC·전역 등록, 잠금 외형을 보존합니다. 기존 키트 적용 경로가 먼저 적용 가능성을 검사하므로 사용할 수 없는 외형 때문에 기존 외형부터 지워지지 않습니다.
- 거부되어야 할 조건 액션 이동이 출발 카드를 비우거나 도착 카드의 표시/숨김 값만 바꾸던 문제를 수정했습니다. 장비 대상을 검증한 뒤 두 값을 함께 준비하고 출발점 정리까지 성공해야 반영합니다. 정상 이동, 같은 대상의 표시/숨김 값만 변경, 중복·오래된 요청 처리는 유지합니다.
- 장비 갱신·조건 평가 대기 작업에 고유 작업 번호와 로드 세대 검사를 적용했습니다. 이전 작업이 새 월드에서 실행되거나 새 작업의 대기 표시를 지우지 못합니다. 정상적인 중복 합치기와 필요한 후속 갱신은 유지합니다.

## 추가 수정

- 로드 뒤 늦게 도착한 SOS 콜백이 새 장비 결과를 덮어쓰던 문제를 수정했습니다. 두 단계 모두 오래된 요청을 거르며 정상 요청·재시도·액터별 독립성은 유지합니다.
- UI 종료 시 SFS가 잠근 조작만 복구하고 현재 엔진의 저장된 조작 잠금을 존중합니다. 창 종료 경로에서도 SFS 소유 상태를 정리합니다.
- 키트 저장 전에 최종 경로를 검사합니다. 정상 하위/한글 폴더·덮어쓰기는 유지하고 상위 이탈·절대 경로·외부 junction을 거부합니다. 실제 저장에는 원래 가상 Data 경로를 유지합니다.
- 조건 JSON의 중복·예약 정의 ID와 ID 카운터 오버플로를 반영 전에 거부합니다. 가져오기 준비 중 조기 액터 갱신도 제거했습니다. 정상 내장 조건 참조·EditorID·외부 함수 이름은 유지합니다.
- 한글·중문의 외형 보호/조건 미적용 설명 누락을 보완하고 잘못된 키트 경로 안내 및 번역 키 누락 검사를 추가했습니다.

v1.6.8 대비 런타임 파일은 SFSCore.dll과 번역 JSON 3개만 변경합니다. 기존 설정·키트·세이브·선택형 패치를 유지하세요.

## 변경 범위

저장·설정 형식, API ABI, 지원 게임 버전, 선행 모드, 선택형 패치, 실제 인벤토리 조작, RaceMenu 분기, DAVE/DAV/네이티브 렌더 소유권은 변경하지 않습니다. 전체 탐색, 백그라운드 스레드, 반복 폴링, 액터·작업 이력 저장소도 추가하지 않았습니다. 기존 모프·하이힐·염색 자원 정리는 유지합니다.

이미 이전 버전에서 지워진 조건부 카드를 자동 복구하는 수정은 아닙니다. 필요한 경우 이전 세이브·내보내기 자료에서 복원하거나 다시 등록해야 합니다.

## 검증

release·releasedbg 설정 모두 회귀 실행 파일 28개와 소스 검사를 통과했습니다. SE/AE DLL 빌드, 내부 버전 1.6.9.0, 기존 export 이름 16개 유지도 확인했습니다.

제품 함수 기반 검사에 잘못된/정상 액션 이동, 같은 대상의 표시 값 변경, 충돌 시 원본 보존, Grid 128회 전환, 로드 경계 128회, 동시 큐 등록, 등록 중 취소, SKSE 인터페이스 부재, 정상 후속 갱신을 포함했습니다. 엔진의 키트 투영과 작업 실행 경계는 테스트 대역이며 실제 게임 검증은 아닙니다. 세부 결과와 한계는 [기술 기록](V1.6.9-TRANSACTION-REGRESSION-FIXES.md)에 정리합니다.

인게임 테스트, 실제 GPU 메모리 측정, SkyUI 열기 시간 측정은 하지 않았습니다. 별도로 기록한 입력 이벤트 포인터 수명 위험은 이번 수정에 포함하지 않았습니다.

추가 검사에는 SOS 로드 128회·두 단계의 지연 콜백·정상 재시도·조작 소유권·조건 저장소 무결성을 포함했습니다. Windows 내부/외부 junction 검사도 통과했습니다. 엔진·VM·ImGui 경계는 테스트 대역입니다. 외부 네이티브 모드가 이미 꺼진 조작을 저장 상태 변경 없이 다시 끄는 경우는 소유권을 관찰할 수 없어 해결을 보장하지 않습니다. [상태 경계 검증](V1.6.9-STATE-BOUNDARY-FIXES.md)에 한계를 명시했습니다.
