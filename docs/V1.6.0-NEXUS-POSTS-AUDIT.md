# SFS v1.6.0 Nexus Posts Audit

Source: <https://www.nexusmods.com/skyrimspecialedition/mods/187128?tab=posts>

Reviewed 2026-09-08 while signed in, across both available Posts pages. The
page header reported 153 comments. The DOM exposed 157 page entries before
deduplication: 95 on page 1 and 62 on page 2, including the same two sticky
posts on both pages. Thus 155 distinct rendered entries were inspected (153
ordinary comments plus two sticky posts).

This document records every actionable feedback family and also protects
intentional behavior from being changed as though it were a defect. Individual
thanks, installation confirmations, author replies that only repeat a nearby
report, and unrelated external-mod support conversations are covered by their
corresponding family rather than duplicated line by line.

## Download/Post Timeline Attribution

Nexus shows comment and download-history timestamps in the same site display
timezone, so they can be compared directly. For each defect report below, the
version attribution uses the latest relevant SFS main file or compatibility
patch downloaded **at or before** the post. A later download is never projected
back onto an earlier report. Download history proves only that the account
downloaded a file; it does not prove that the file was installed, enabled, or
the build that produced a supplied log.

Patchless compatibility remains preferred, but it must be implemented by the
consumer adopting SFS's stable final-display API. SFSCore does not globally
fake `GetWornArmor`, rewrite third-party saves, or replace unrelated MCM files
merely to eliminate a narrowly scoped compatibility package.
