# SFS v1.6.0 Feedback Regression Ledger

Post-release correction (v1.6.1): a new wig/clothing display report exposed a
confirmed custom-skin hook installation regression and a production trampoline
read-window defect. See `V1.6.1-DISPLAY-REGRESSION-AUDIT.md`. The reporter's
environment and in-game fix result are unknown; earlier source/static coverage
must not be interpreted as complete in-game parity.

This ledger promotes previously fixed user-visible failures into permanent
v1.6.0 compatibility requirements. A refactor is incomplete if any row is not
covered by an automated check, a focused static boundary review, or an explicit
in-game matrix case.

Nexus-origin rows are version-attributed from the latest relevant main or patch
download at or before each report, never from a later download. See
`V1.6.0-NEXUS-POSTS-AUDIT.md` for the timestamp-by-timestamp evidence and its
installation/activation caveat.

## Required Capture For New Feedback

Record the SFS build, Skyrim runtime, SKSE and RaceMenu interface versions,
display backend, actor type, save lifecycle, pause/preview state, strip-link
mode, relevant options, external-mod versions, reproducible steps, observed and
expected result, logs, and whether the result reproduces without the optional
compatibility patch. Unconfirmed reports remain test scenarios and are not
discarded.
