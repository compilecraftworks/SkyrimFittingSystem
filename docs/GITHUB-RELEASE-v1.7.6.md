## English

- Added official optional OStim and OStim Standalone Strip Link patches v1.0.0, requiring SFS v1.7.6 or later.
- Connect Mod Settings and Vanilla Slots strip/redress linking, including both Direct Edit bases. Preserve slot protection, NoStrip and each framework's wig policy.
- Support full, partial and animated appearance redress with actor/session-scoped ownership. Keep actual equipment and OStim's equipment arrays under OStim's control.
- Move automatic vanilla wig linking to LongHair slot 41 without changing 31+42 helmet handling or explicit saved mappings.
- Hide pure registered slot-41 wigs under visible hair-covering helmets and restore them when the helmet is hidden or removed, including Helmet Toggle 2. Preserve manual hiding and locked appearances.
- Retain existing native/DAV/DAVE rendering, BodyMorph, high heels, dye, conditions, IED and public API behavior. No periodic actor/inventory scan or new mandatory dependency was added.

Validation: SE/AE-only build, both Papyrus patch variants and 42 regression executables plus source-boundary checks passed. Real in-game OStim scene timing/save-load remains unverified.

Update: Keep settings, kits and saves. OStim is optional. Use SFS v1.7.6 or later and exactly ONE matching OStim patch v1.0.0. Let its OUndress.pex win conflicts, then restart/reload. Patches contain no OStim DLL or ESP; full corresponding sources for both are included in the SFS Source ZIP.

## 한국어

- SFS 1.7.6 이상용 OStim·OStim Standalone 탈의 연동 패치 1.0.0을 정식으로 추가했습니다.
- 모드 설정 연동·바닐라 슬롯 연동과 직접 편집의 두 기준을 연결합니다. 슬롯 보호·NoStrip·각 프레임워크의 가발 설정을 유지합니다.
- 전체·부분·애니메이션 재착의를 액터·장면별 소유권으로 연결합니다. 실제 장비와 OStim 착용 장비 배열은 OStim이 계속 관리합니다.
- 바닐라 자동 가발 연동을 LongHair 41번으로 조정했습니다. 31+42 투구 처리와 사용자가 저장한 명시적 매핑은 변경하지 않습니다.
- 표시 중인 머리 덮는 투구에 따라 순수 등록 41번 가발을 숨기고, 투구를 숨기거나 벗으면 복원합니다. Helmet Toggle 2에도 적용하며 수동 숨김·잠긴 외형은 보존합니다.
- 기존 native·DAV·DAVE 렌더, 바디모프·하이힐·염색·조건·IED·공개 API 동작을 유지합니다. 주기적 액터·인벤토리 스캔이나 새 필수 선행 모드는 추가하지 않았습니다.

검증: SE/AE 전용 본체 빌드·두 Papyrus 패치·회귀 실행 파일 42개와 소스 경계 검사를 통과했습니다. 실제 인게임 OStim 장면의 타이밍·진행 중 세이브 로드는 별도 미검증입니다.
