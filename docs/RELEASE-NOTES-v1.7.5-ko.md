# Skyrim Fitting System v1.7.5 SE-AE

## 변경 사항

- SexLab이 실제 신발을 탈의한 뒤 SFS 등록 하이힐 높이가 남아 애니메이션 위치가 어긋날 수 있던 경로를 수정했습니다.
- SexLab의 기존 RemoveHeelEffect 설정과 NPC 높이 보정을 따릅니다. SFS가 관리하는 자동 하이힐 높이를 해당 보정에 맞춰, 보정 누락이나 이중 적용을 방지합니다. SexLab 자체의 변환 키는 변경하지 않습니다.
- 등록 외형을 숨겼을 때 표시 백엔드가 이전 노드를 아직 제거하지 않았더라도 오래된 높이를 해제합니다. 실제로 표시되는 착용 신발의 HH_OFFSET/SDTA, 동일 장비가 실제 장비로 계속 표시되는 경우와 SDTA의 X/Y 성분은 보존합니다.
- 구형 NiOverride와 신형 NiTransform에 같은 정책을 적용해 native·DAV·DAVE에서 사용합니다. 발 장비 탈의 OFF, 일반 신발, 재착의 OFF로 끝나는 이벤트, 수동 외형 표시와 다른 모드의 이름 있는 변환을 회귀 검사에 포함했습니다.
- 일반 SexLab/P+ 씬 이벤트의 참가자만 관찰하며, 종료·삭제·세이브/초기화 경계에서 씬 소유권을 정리합니다. 주기적 액터 검색·인벤토리 메뉴 스캔·강제 3D 갱신·실제 장비 착용/해제·SexLab 스크립트 교체는 추가하지 않았습니다.

## 업데이트 안내

본체 전체 패키지를 설치하고 기존 설정·키트·세이브를 유지하세요. 런타임 패키지에서는 SFSCore.dll만 변경됩니다. 선행 모드·지원 게임 버전 목록·보조 ESL·스크립트·공개 API·선택 호환 패치는 그대로입니다. SexLab과 RaceMenu가 새 필수 선행으로 추가되는 것은 아닙니다.

애니메이션 높이 처리는 SexLab의 RemoveHeelEffect 설정을 따르며, 해당 옵션이 꺼진 씬에 새 하이힐 제거 정책을 강제하지 않습니다. 기존 외형 탈의/재착의 정책과 실제 장비 제어 주체도 유지합니다.

## 검증 범위

SE/AE 전용 릴리즈 빌드, 회귀 검사 38개와 소스 검사를 통과했습니다. 실제 생산 코드로 하이힐 동기화 236건, 루트·메타데이터·생명주기 1,195건, SexLab 이벤트 어댑터 19건을 검사했습니다. NiTransform 1/2 구형 경로와 3/4 공개 경로는 기록용 대체 인터페이스로 실행했으며, 상위 버전 호환 API 구간 검사는 모델 검사이지 미출시 바이너리 검증이 아닙니다.

SexLab 보정 없음/정상/오래된 값, 발 장비 탈의 ON/OFF, 일반 신발, 숨김 후 늦은 노드 제거, 실제 신발, 타 모드 변환, 콜백 실패·취소, 재착의 OFF, 씬 재배정, 액터 삭제와 로드 세대 경계를 포함합니다. 바디모프·염색·실제 장비 착용 충돌·탈의/DD/P+·IED·UI·API·성능의 기존 회귀 검사도 통과했습니다.

새 DLL로 인게임 애니메이션 테스트를 수행한 것은 아닙니다. 지원 런타임의 공통 어댑터와 CommonLib의 SE/AE 전용 alias 접근자를 사용하지만, 모든 게임/RaceMenu/SexLab 배포본과 모드 조합을 각각 실행했다는 의미는 아닙니다.
