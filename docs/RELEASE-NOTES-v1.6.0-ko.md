# Skyrim Fitting System v1.6.0

v1.6.0은 v1.5.7의 전체 기능을 기준으로 구조와 무결성을 재정비하는
릴리스입니다. 장비·의상·키트·조건·작업대·키트 생성기·옵션 탭, 실제 장비와
등록 외형의 전역/개별/조건 숨김, 네 가지 탈의 연동, 보호 슬롯·방패·일시정지,
염색/DDS 필터, RaceMenu 및 저장 호환을 삭제하거나 축소하지 않습니다.

## 변경 사항

- 조건 카드 드래그앤드롭을 64비트 고정 UI identity 기반의 원자 트랜잭션으로
  변경했습니다. 빈 칸 이동과 차 있는 카드 교환은 양쪽을 한 번에 검증·반영하며,
  오래된 payload·중복 identity·충돌·없는 대상은 어느 쪽도 지우지 않습니다.
- 조건 행과 조건부 표시 규칙의 ImGui ID도 변하는 벡터 인덱스 대신 고정
  identity를 사용합니다.
- `ConditionDropLogicTests`를 전체 빠른 회귀 묶음에 추가했습니다.
- 실제 장비와 등록 외형에 전역/개별 숨김, 조건, 자동 억제, 임시 표시,
  보호 슬롯, 잠금, 미리보기를 적용한 최종 렌더 외형 질의 경계를 만들었습니다.
  누드 판정, OAR 표시 조건, 제한된 몸통 키워드 호환, Dynamic Footprints 호스트
  API가 이 동일한 결과를 사용합니다.
- Virtual Worn Token을 `poc` 경로와 실험용 빌드 플래그에서 정식
  `features/virtual_tokens` 모듈로 승격했습니다. 기존 ESL FormID, Papyrus 이름,
  직렬화 레코드와 네 가지 탈의/재착의 방식은 그대로 유지합니다.
- 실제 배포 중인 Devious Devices 숨김/탈의 브리지도 예전 `poc` 경로에서 정식
  `features/devious_devices` 어댑터로 승격했습니다. 이벤트·가시성·트랜잭션
  동작은 바꾸지 않았습니다.
- 키트 생성기 UI가 내부 변경 가능 컨테이너를 직접 받지 않도록 바꾸고, 플러그인
  선택·이름 변경·후보 선택·구성품 교체를 검증된 명령으로 처리합니다. 키트 묶음
  판단 기준과 백그라운드 적합성 평가는 계속 독립적으로 갱신할 수 있습니다.
- 기능 동등성 계약, 호환 패치 판단표, 과거 사용자 피드백 회귀 원장을
  추가했습니다.
- BodyMorph 추적 상태를 RaceMenu 모듈의 단일 소유권으로 고정했습니다. 장비,
  의상, 조건, 키트/생성기, 보호/방패 슬롯, HT2, 염색, 일시정지 카메라/포즈,
  네 가지 탈의 방식, P+, DD, DAVE/DAV/native 갱신을 차례로 수행해도 유지된
  등록 외형 노드가 직접/지연 모프 갱신을 계속 받는 교차 회귀를 추가했습니다.
- IED custom-skin 경로는 SFS 필터 visitor를 IED의 다른 concrete visitor ABI로
  넘기지 않습니다. 정확한 IED 체인에서는 원본 엔진 visitor로 필터한 뒤 IED
  공개 액터 Evaluate를 지연 호출하며, 헬겐/새 게임 초기화처럼 체인이 아직
  불명확한 상태에서는 안전한 일반 엔진 경로로 닫힙니다.
- IED가 CommonLib/SKSE 중간 트램펄린 뒤에 있는 경우에도 검증된 무조건 점프
  연쇄를 따라 실제 DLL 소유자를 판별합니다. 확인할 수 없는 체인에는 SFS
  custom-skin 훅을 겹쳐 설치하지 않습니다.
- 조건 액션 카드 이동과 사용자 조건 절 순서 변경은 첫 마우스 릴리스에서만
  처리합니다. 대상 교체/변환, 출발점 정리, 표시 극성, 탈의·DD 자동화 정리를
  임시 상태에서 모두 성공시킨 뒤 한 번에 반영하며 오래된 payload는 무변경으로
  거부합니다.
- Dynamic Footprints 연동은 SFS 비관리 액터와 최종 렌더상 맨발인 액터를
  구분합니다. 따라서 실제 신발이 기술적으로 착용 중이어도 SFS가 숨긴 경우
  그 신발로 다시 폴백하지 않습니다.
- 첫 설치의 설정 저장소를 렌더러/메뉴 훅보다 앞선 `SFSCore.dll` 로드 시점에
  준비하도록 바꿨습니다. 런타임 ZIP에는 MO2/Vortex에서 반드시 SKSE64로
  실행해야 한다는 점과 `Toggle UI Button`이 Skyrim의 ESC 조작 설정이 아니라
  F6으로 여는 SFS 내부 Options에 있다는 점을 설명한 설치 안내가 포함됩니다.
- 저장 불러오기와 되돌리기는 하나의 멱등 생명주기 경계를 공유합니다. 새
  코세이브 레코드를 읽기 전에 장비·이벤트 싱크·SOS·BodyMorph 예약 작업을
  먼저 무효화한 뒤 염색 렌더러, 탈의/DD/토큰, HT2, DAVE, 슬롯, 캐시와 임시 UI
  상태를 정리하므로 이전 월드의 지연 작업이 새 월드에 재적용되지 않습니다.
- 피팅 염색 팝업에 흰색은 원본 디퓨즈에 곱하는 중립값임을 명시했습니다.
  따라서 어두운 원본을 흰색으로 만드는 기능처럼 오해하지 않으면서 기존의
  안전한 곱셈 염색 방식을 유지합니다.

## 호환 패치

패치 없는 호환을 우선합니다. Wet Function의 누드 자동 적용은 이미 MCM 교체
없이 SFS 최종 몸통 표시 상태를 따릅니다. 다만 Wet Function 효과 스크립트,
DFFMA OAR JSON, Dynamic Footprints의 검증된 단일 호출 지점 브리지는 외부 모드가
SFS 질의를 직접 채택하기 전까지 필요합니다. 이를 SFSCore에 억지로 흡수하면
전역 장착 판정을 속이거나 동일한 버전 종속 바이너리 패치를 본체에 넣게 됩니다.

DFFMA FOMOD 패키지는 1.4.4.1로 갱신했습니다. 선택형 GS Hovering 항목 8개에
FOMOD 5 스키마의 필수 `description`이 빠져 Vortex가 설치 화면 전에 XML을
거부하던 문제를 수정했습니다. 설치되는 OAR JSON은 바뀌지 않았으며, 이후
패키징에서는 모든 선택지의 요소 순서와 원본 폴더를 자동 검증합니다.

Wet Function v1.2.0 호환 아카이브도 전용 내용 검증기와 빌더를 사용합니다.
아카이브에는 `WetFunctionEffect.pex`와 안내문만 들어가며,
`WetFunctionMCM.pex`, 저장 설정, 플러그인과 네이티브 DLL은 자동 거부됩니다.

Dynamic Footprints 호환 DLL의 내부 버전, README, 바이너리 리소스와 아카이브를
모두 1.6.0으로 통일했습니다. 패키지 빌더는 버전/구성 불일치를 거부하며,
v1.4.5에서 도입한 Dynamic Footprints v3.0 전용 해시·시그니처 검증과 정확한
호출 지점 인접 트램펄린 안전 경계는 그대로 유지합니다.

## 검증

- `releasedbg` `SFSCore.dll`은 파일/제품 버전 1.6.0.0으로 빌드됩니다.
- Skyrim 런타임 레이아웃, 키트 생성기, BodyFamily, 조건, 조건 드롭, 염색,
  키트 이동, 핵심 동작, RaceMenu ABI, morph 추적을 포함한 전체 빠른 회귀 묶음이
  통과했습니다.
- 자동 검증은 실제 렌더와 선택 모드 소유권을 확인하는 문서화된 SE/AE 인게임
  조합표를 대체하지 않습니다.
