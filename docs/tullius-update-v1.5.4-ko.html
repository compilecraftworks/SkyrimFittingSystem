Skyrim Fitting System v1.5.4

  • 구형 RaceMenu 사용 시 메인 메뉴에 진입하기 전에 CTD 또는 무한 대기가 발생할 수 있던 v1.5.3 초기화 오류를 수정했습니다.
  • 구형·신형 ActorUpdateManager 인터페이스를 분리하고, 기존 등록 외형 부착 콜백과 중복 등록 방지를 유지했습니다.
  • 실시간 BodyMorph와 등록 하이힐 연동에서 검증된 RaceMenu 인터페이스를 버전별로 선택합니다. 미확인 버전은 안전하게 건너뛰며, 모든 과거·미래 RaceMenu 버전을 지원한다는 의미는 아닙니다.
  • 구형 하이힐 갱신이 실패했는데도 임시 변환 정리 후 성공으로 기록되던 문제를 수정했습니다.
  • 버전별 ABI·콜백·초기화 재시도 회귀 테스트를 추가했습니다. 기존 액터별 구조, DAVE·DAV·native, 탈의·재착의 연동, 외형 잠금과 염색 동작을 유지하며 별도 RaceMenu 패치는 필요하지 않습니다.
