# Skyrim Fitting System v1.7.1 SE-AE

## 변경 사항

- 같은 Papyrus 스크립트 타입을 반복 조회할 때 전역 함수 목록을 불필요하게 다시 검사하던 처리를 줄였습니다. 최초 호출 전 훅 설치와 첫 지연 검사는 유지하며, 타입·목록 변경, 늦은 native 등록, 로드·초기화 시에는 다시 검사합니다.
- 일반 아이템의 `Form.HasKeyword`, `GetKeywords`, `GetNumKeywords`, `GetNthKeyword` 조회에서 결과에 사용하지 않는 호출자 추적을 제거했습니다. 실제 가상 토큰의 등록 외형 연결은 유지합니다.
- 미완성 목록이나 설치에 실패한 훅을 완료로 기록하지 않도록 했습니다. SexLab P+의 두 멤버 관찰 경로는 지연 검사와 재시도 소진 후 후속 조회에서의 복구를 포함해 기존 동작을 유지합니다.
- 설치 검사 이력을 최대 128개로 제한하고 로드·리버트 시 참조를 정리합니다. 액터·외형·인벤토리·나체 판정 결과를 저장해 재사용하는 캐시는 아닙니다.

## 유지되는 동작과 설치

최종 렌더 상태에 따른 나체 판정과 탈의·재착의 연동은 계속 작동합니다. 착용 조회, 장비 변경 감지, 카탈로그 필터, DD, P+ 경로를 유지합니다. DAVE/DAV/네이티브 선택, RaceMenu 인터페이스, 바디모프, 하이힐, 염색, IED 연동, 지원 게임 버전, 선행 모드, 세이브 형식, API ABI는 변경하지 않았습니다.

1.7.0 대비 런타임 ZIP에서는 `SFSCore.dll`만 변경됩니다. 기존 설정·키트·세이브·VirtualTokens ESL·선택형 호환 패치는 유지하세요. 새 선행 모드, 실제 장비 조작, 주기적 폴링, 임시 런타임 진단 코드는 추가하지 않았습니다. 선택형 패치 버전도 그대로입니다.

## 검증과 한계

전역 함수 12개를 가진 동일 타입을 256회 조회하는 분리 검사에서 함수 항목 검사가 3,096회에서 24회로 줄었고 최초 호출 설치는 유지됐습니다. 일반 아이템 키워드 조회의 불필요한 호출자 추적도 제거됐습니다. 이는 독립 검사에서 센 작업 횟수이며 게임 프레임 시간이나 대화 지연 측정값은 아닙니다.

29개 회귀 검사에는 새 처리 경로와 기존 조건/UI, 렌더 상태 API, IED, RaceMenu·모프·하이힐, 탈의연동, 자원 수명 검사가 포함됩니다. 검증 범위와 릴리즈 확인 내역은 [기술 기록](NPC-DIALOGUE-PERFORMANCE-2026-09-24.md)을 참고하세요.

**제보된 NPC 대화 멈춤을 인게임에서 재현하거나 시간을 측정한 것은 아닙니다.** 조사 과정에서 확인한 불필요한 반복 작업을 제거한 업데이트이며, 모든 대화 지연이나 모드 조합이 해결됐다고 보장하지 않습니다. ESL 없는 구버전으로 내릴 때 DLL도 함께 바뀌므로 ESL 자체를 확정 원인으로 안내하지 않습니다.
