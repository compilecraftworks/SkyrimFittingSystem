# Skyrim Fitting System v1.6.1

다른 플러그인이 먼저 설치한 스킨 CALL 훅을 식별하지 못하면 등록 가발·의상을
붙이는 과정까지 건너뛰던 v1.6.0의 코드상 회귀를 수정했습니다. 식별되지 않은
훅에는 게임이 전달한 원래 객체를 유지하고 SFS 등록 외형 부착을 계속합니다.

- 검증된 엔진 경로의 필터링과 IED의 안전한 엔진 필터·액터 갱신 경로를 유지합니다.
- 미식별 CALL 훅도 원래 엔진 객체의 콜백에서 실제 장비 숨김을 적용합니다.
  객체·vtable 포인터·RTTI·내부 필드를 유지하며, 스레드와 visitor별 범위를
  중첩 호출·예외 종료 후 복원합니다. 인벤토리·착용 플래그는 변경하지 않습니다.
- ENDBR64가 붙은 긴 중계 코드와 읽기 가능한 페이지 끝의 짧은 중계 코드를
  정상적으로 추적하도록 보완했습니다.
- 실제 SE·AE 훅 기계어를 실행해 외부 객체 보존, 외형 부착 호출 및 전달 인자를
  확인하는 회귀 테스트를 추가했습니다.
- v1.6.0 저장·설정 형식을 유지합니다. 선행 모드와 별도 패치 추가는 없으며,
  기존 선택 호환 패치 버전도 그대로입니다.

초기화·호환 경로도 추가로 점검했습니다.

- RaceMenu 일부 인터페이스만 준비돼도 초기화를 끝내던 문제를 수정했습니다.
  연결된 기능은 유지하고 빠진 연결·훅만 재시도합니다. 더 높은 인터페이스 버전은
  번호만으로 차단하지 않고 마지막 호환 API 구간을 사용하며 가정을 로그에 남깁니다.
- DAVE 초기 API 실패는 모든 DataLoaded 처리 후 다시 확인합니다. 공개 갱신 실패도
  액터별 엔진 재구성과 염색·포즈·하이힐 후속 복원을 거치도록 보완했습니다.
- 늦게 부착된 등록 외형의 염색 복원을 BodyMorph 가용 여부와 독립시켰습니다.
- Grid Costume의 상위 ABI·추가 필드는 기존 메시지 구간으로 연결합니다.
  잘못된 길이·개수 검사와 세이브 복원 시 기존 등록 외형 보호는 유지합니다.
- OAR API·조건 등록 실패는 이후 초기화 단계에서 재시도하고 성공한 등록은 유지합니다.
- 회귀 테스트 실행 파일 12개와 부가 검사를 통과했습니다. RaceMenu 공식 소스의
  관련 변경 시점 19개를 분석했지만 모든 배포 ZIP을 바이너리 검증한 것은 아닙니다.

상위 버전의 하위 호환 연결은 명시적인 가정입니다. 미래 버전이 함수 순서나
메시지 의미를 바꾸는 경우까지 보장하지는 않습니다. 상세 분류·미확보 배포본은
`RaceMenu-Version-Compatibility-v1.6.1.md`에 기록했습니다.

피드백 작성자의 게임 버전·모드 구성은 확인되지 않았습니다. 코드상 결함은
테스트로 재현했지만 해당 사용자의 인게임 해결 여부까지 확인한 것은 아닙니다.
미식별 훅 수정은 원래 엔진 visitor 인터페이스를 통한 장비 처리에 적용됩니다.
외부 플러그인이 이 인터페이스 밖에서 임의로 그리는 모델까지 보장하는 것은
아닙니다. 기존 vanilla/DAV/DAVE 및 worn-mask 숨김 경로도 유지됩니다.

상세 근거와 검증 범위는 `V1.6.1-DISPLAY-REGRESSION-AUDIT.md`를 참조하십시오.
