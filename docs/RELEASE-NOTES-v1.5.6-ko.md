# Skyrim Fitting System v1.5.6

- 염색 대상 diffuse를 활성 D3D11 바인딩뿐 아니라 Skyrim 렌더러 상태에도
  렌더 패스 단위로 동기화하도록 수정했습니다. 조각 범위를 벗어나지 않으면서
  Community Shaders·ENB·ReShade·업스케일러 렌더 체인과의 호환성을 높였습니다.
- UBE·CBBE/3BA·UNP/BHUNP 의상 조각 판정을 확장했습니다. 실제 바디·생식기·
  오버레이와 normal·mask·cubemap 자원은 계속 염색 대상에서 제외합니다.
- Helmet Toggle 2의 소유 경계를 복원했습니다. 실제 투구는 HT2가 계속 제어하고,
  등록 외형 투구는 액터별 HT2 상태를 따르며, 원시 방어구 슬롯으로 머리·헤어
  표시 상태를 다시 덮어쓰지 않습니다.
- `sslActorAlias` 타입 연결 완료 후 P+ 멤버 네이티브를 제한적으로 재검사해
  로드 순서에 따라 `StripByData`·`StripByDataEx` 훅이 빠지던 문제를
  수정했습니다. 기존 모드 설정·바닐라·직접 편집 탈의/재착의 resolver와
  액터별 상태는 그대로 사용합니다.
- 설치 환경에 따라 SOS와 TNG를 분리 처리합니다. 내부 생식기·커버 폼은 일반
  장비·의상·키트 목록과 탈의 트랜잭션에서 제외하고, 보통 32/49 슬롯 의상의
  노출·가림·커버·속옷 판정은 유지합니다.
- Modex/SFS 키트 JSON 호환성을 개선했습니다. 설치되지 않은 의상 조각만
  제외하고 나머지 조각은 사용할 수 있으며, 잘못된 UTF-8·긴 이름·개별 파일
  저장 실패에도 키트 생성 전체가 중단되지 않게 했습니다.
- 커스텀 조건의 이중 부정 정규화, 스크롤바 드래그 위치 유지, 메뉴 카메라
  재진입, 키트 목록 키보드·게임패드·WASD·더블클릭 경로를 수정했습니다.
  실제 텍스트 입력 포커스의 입력 차단 범위는 유지합니다.

런타임은 SE/AE 공용 `SFSCore.dll` 하나이며 PDB, 교체 DLL, SexLab P+
PEX/ESP, Helmet Toggle 2 패치를 포함하지 않습니다. DAVE·DAV·native의
액터별 소유 구조, RaceMenu 실시간 BodyMorph/OBody, 외형 잠금, 하이힐 높이,
저장 데이터 경계는 유지됩니다.

빠른 회귀 테스트는 런타임 레이아웃, 조건, 키트 파싱·조작, 염색 규칙,
액터별 표시·탈의 트랜잭션, RaceMenu ABI·모프 추적, Helmet Toggle 2 규칙,
SOS/TNG 분류를 검사합니다. 실제 렌더 결과는 사용 중인 렌더러·선택 모드
환경에서 인게임 확인이 필요합니다.
