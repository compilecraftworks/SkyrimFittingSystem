# Skyrim Fitting System v1.7.3 SE-AE

## 변경 사항

- OCF 등 분류용 키워드에 포함된 상의 관련 단어 때문에 일반 32번 갑옷에
  노출 판정이 붙던 문제를 수정했습니다. 상의 자동 판정은 장비 이름·EditorID만
  사용하며, SOS/TNG 런타임 키워드와 가상토큰에 같은 수정 결과를 적용합니다.
- `Top`, `Upper`, `Chest`, `Crop`, `Tube`, `Breast`, `Halter` 같은 모호한 단어
  하나만으로 노출을 판정하지 않도록 개선했습니다. 브라·셔츠·조끼·비키니 상의·
  크롭탑 등 명확한 이름과 기존 한·중 분류는 유지합니다. 일반적인 영문 복수형도
  지원하며, Shirtless·Vestments 같은 접두어 오탐과 서로 다른 항목 문자열을
  이어 붙여 생긴 가짜 구문은 제외합니다.
- SOS 수동 노출·가림 설정, 49번 하의 처리, 다른 모드가 원래 부여한 키워드는
  보존합니다. SOS API의 중복 탐색을 제거하고 설치 감지 시 확인한 폼을 공유합니다.
  SOS와 TNG는 각각 설치된 경우에만 해당 연동이 활성화됩니다.
- DAV + Helmet Toggle 2 환경에서 실제 장비의 원본 슬롯이 머리·얼굴 숨김 상태를
  다시 덮어쓰던 경로를 수정했습니다. DAV와 DAVE 모두 변형 모드가 계산한 표시
  마스크를 보존하며, 등록 외형·SFS 실제 장비 숨김·기존 HT2 머리카락 처리는
  유지합니다. 실제 장비의 착용·해제나 인벤토리는 변경하지 않습니다.

## 업데이트 안내

본체 전체 패키지를 설치하세요. 기존 설정·키트·세이브는 유지합니다.
OCF를 제거하거나 SOS/TNG 지원을 끌 필요는 없습니다. 이름 분류는 메시 분석이
아닌 추정이며, 이름이 모호한 상의는 기존 SOS 수동 설정으로 지정할 수 있습니다.

선행 모드·지원 게임 버전·공개 API ABI·저장 형식·보조 ESL과 Wet Function /
Dynamic Footprints / Modesty 선택 패치는 변경하지 않았습니다. 바디모프·하이힐·
염색·탈의/재착의 트랜잭션·IED 훅 경로도 교체하지 않았습니다.
새 액터 순회·인벤토리 스캔·장면 노드 보관·런타임 진단 코드는 추가하지 않습니다.
