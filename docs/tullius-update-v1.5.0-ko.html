v1.5.0 업데이트 내역

  • 작업대 기본·조건 영역 등록 외형 카드에 피팅 염색을 추가했습니다. 염색 버튼이나 카드 우클릭 메뉴에서 열고, 외형 조각의 짧은 월드 점멸로 대상을 확인한 뒤 색상을 적용하거나 원본 색상으로 복원할 수 있습니다.
  • 색상은 액터 FormID·등록 외형 ARMO·정확한 렌더 조각 단위로 저장됩니다. 같은 메시나 diffuse를 쓰는 다른 액터·다른 등록 외형으로 번지지 않으며 모호한 일치는 추측하지 않습니다.
  • 염색은 전용 geometry 렌더 텍스처만 사용하며 원본 DDS/NIF·실제 장비·인벤토리·작업대 행·조건·키트·가상토큰·외부 탈의/재착의·DAVE/DAV/native 상태를 바꾸지 않습니다.
  • 별도 Helmet Toggle 2 PEX 패치를 없애고 SFSCore 본체가 정확한 플레이어·NPC·팔로워 HT2 상태 신호만 액터별로 관찰하도록 교체했습니다.
  • HT2의 중복 제거된 배열 위치가 아니라 실제 투구 ARMO의 전체 슬롯 마스크를 읽습니다.
  • HT2가 착용 상태인 실제 31+42 투구를 숨길 때 해당 액터의 스키닝 worn-mask에서 실제 31 Hair 비트만 해제해 원래 머리카락을 표시하고 대머리 현상을 막습니다. 실제 ARMO·인벤토리·키워드·HT2/DAVE 변형은 바꾸지 않습니다.
  • 순수 등록 31번은 독립적으로 유지하고 등록 31+42는 42번을 통해 따릅니다. 플레이어·팔로워·NPC는 주기적 폴링이나 주변 액터 스캔 없이 액터별로 처리합니다. 모드 설정 머리 슬롯 가상토큰·바닐라 자동 연동·직접 편집·수동 눈 버튼·외부 탈의·재착의·DAVE/DAV/native 동작은 그대로 유지됩니다.
  • 기존의 모든 SFS Helmet Toggle 2 호환 패치는 삭제하십시오. 이제 HT2는 별도 SFS 패치가 필요 없습니다.
