# Skyrim Fitting System v1.4.8

## 액터 선택 목록 안정성

- 작업대 액터 선택 목록에서 플레이어가 있는 현재 로드 셀을 먼저 열거하고,
  기존 4096 단위 TES 반경 검색을 이어서 수행하도록 보완했습니다.
- 두 경로는 같은 액터별 선택 조건, 반경, 중복 제거, 거리순 정렬, 최대 32명
  제한을 사용합니다. 저장된 행·조건 규칙·등록 외형·실제 장비는 바꾸지 않습니다.

## 빌드 의존성

- 빌드 의존성을 CommonLibSSE-NG v6.7.0
  (`3d81614617910e7f34b33d8750881811b5e36445`)으로 갱신했습니다.
- 이 변경으로 Skyrim VR 지원이 추가되지는 않으며, 런타임 지원 범위는 기존과
  같이 SE/AE입니다.
