# Skyrim Fitting System v1.4.8

## 액터 기준 메뉴 캐릭터 표시

- UI의 캐릭터 위치를 왼쪽 또는 오른쪽으로 설정했을 때 이제 항상
  플레이어가 아니라 작업대에서 선택한 액터를 기준으로 표시합니다.
- 조준선 NPC 추가 옵션으로 UI를 열면 처음부터 조준한 NPC를 표시하고,
  작업대 액터 드롭다운을 바꾸면 카메라 대상도 즉시 전환됩니다.
- NPC의 월드 위치는 이동하지 않습니다. 임시 카메라 대상과 방향,
  플레이어 전용 상하 각도 및 카메라 설정은 액터 변경 또는 UI 종료 시
  원래 상태로 복원됩니다.

## 액터 선택 목록 안정성

- 작업대 액터 적합성 판정이 사용하는 CommonLibSSE-NG의 SE/AE 가상함수
  배열을 보정해 `Actor::IsDead()`가 올바른 엔진 슬롯을 호출하도록 수정했습니다.
- 진단 중 시도한 액터 수집 변경은 모두 되돌렸습니다. 선택 조건·주변 반경·
  중복 제거·거리순 정렬·최대 32명 제한을 포함한 수집 방식은 v1.4.5와 같습니다.

## 빌드 의존성

- 빌드 의존성을 CommonLibSSE-NG v6.7.0
  (`3d81614617910e7f34b33d8750881811b5e36445`)으로 갱신했습니다.
- 해당 업스트림 리비전에 적용한 최소 범위의 SE/AE 가상함수 배열 보정과
  적용 경계를 소스 배포본에 문서화했습니다.
- 이 변경으로 Skyrim VR 지원이 추가되지는 않으며, 런타임 지원 범위는 기존과
  같이 SE/AE입니다.
- 재현 가능한 빌드 기준을 XMake v3.1.0, Dear ImGui v1.92.9b,
  nlohmann/json v3.12.0으로 갱신했으며 정확한 리비전과 체크섬은
  `DEPENDENCIES.md`에 기록했습니다.
