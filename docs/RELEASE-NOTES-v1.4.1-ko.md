# Skyrim Fitting System v1.4.1

## 수정 사항

- 실제 장비를 하나도 착용하지 않은 플레이어 또는 NPC에게 등록 외형을 적용해도 즉시 렌더되지 않던 문제를 수정했습니다. 이전에는 반지 착용 같은 추가 장비 변경이 있어야 외형이 표시되는 경우가 있었습니다.
- 실제 장비가 없는 액터의 등록 외형 구성이 변경될 때만 해당 액터의 3D 표시를 한 번 갱신합니다. 전역 액터 검색이나 주기적인 폴링은 사용하지 않습니다.
- 실제 장비와 등록 외형이 모두 없을 때 작업대가 기존 두 열 제목 아래에 하나의 빈 행을 표시하고, 조건 영역 제목이 중복되지 않도록 수정했습니다.

## 업데이트

이전 SFS 모드 폴더를 완전히 삭제한 뒤 v1.4.1 ZIP을 새로 설치하고 `SkyrimFittingSystem-VirtualTokens.esl`을 활성화하십시오. 기존 등록 외형·조건·숨김 데이터와 개인 키트는 그대로 사용할 수 있습니다.
