# Skyrim Fitting System v1.4.7

- Skyrim 커스텀 스킨 재구성의 정확한 `VisitWornItems` 호출을 IED가 선점한 경우에만 작동하는 좁은 호환 경계를 추가했습니다. SFS는 숨긴 실제 장비용 일반 filter visitor를 IED의 구체 visitor 훅으로 더 이상 전달하지 않습니다.
- 해당 숨김 실제 장비 호출은 원본 엔진 대상으로 안전하게 필터링한 뒤, 재구성이 끝난 다음 IED의 공개 액터별 평가를 지연 예약합니다. 예약은 액터별·중복 방지 방식이며 SFS 갱신 상태를 초기화할 때 함께 비웁니다.
- 숨긴 실제 장비가 없는 일반 호출, IED가 아닌 pre-hook 체인, 저장된 외형 데이터, 모드 설정 슬롯 연동·바닐라 슬롯 자동 연동·직접 편집, 외부 탈의/재착의 트랜잭션, DAVE/DAV/native 표시 백엔드는 변경하지 않습니다.
