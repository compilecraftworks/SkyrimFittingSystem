# Skyrim Fitting System v1.6.8 SE-AE

## 변경 사항

- 실제 오브젝트 언로드·폼 삭제 시 해당 액터의 등록 외형 모프·하이힐 씬 참조를 해제합니다. 액터를 더 이상 조회할 수 없어도 FormID로 해당 씬의 대기 작업을 취소합니다.
- 언로드된 액터의 염색 GPU 타깃과 컴포넌트 미리보기를 해제합니다. 저장 색상은 삭제하지 않고 로드·재부착 시 기존의 액터별 제한된 경로로 복원합니다.
- 하이힐·염색 작업에 고유 식별값을 부여해 이전 콜백이 같은 액터의 새 작업을 완료·취소하지 못하게 했습니다. 진행 중인 염색·미리보기 생성도 씬 정리 후 낡은 결과를 등록하지 않으며 다른 액터·컴포넌트는 유지합니다.
- 언로드 때 모프 대상 정보는 유지해 DAVE/RaceMenu가 다음 SFS 갱신 전에 재부착해도 실시간 모프가 이어지도록 했습니다. 일반 숨김·표시·프리뷰·HT2·카메라·탈의·재착의·백엔드 갱신에는 이번 정리를 연결하지 않았습니다.
- 제품 호출자가 없던 부분적 모프 정리 함수를 제거하고 검사된 FormID 기반 수명 정리 경로로 통합했습니다.

## 호환성과 검증

회귀 실행 파일 24개와 소스 검사를 통과했습니다. 128회 언로드·재로드, 서로 다른 액터 128개 삭제, 동일 FormID의 새 작업, 구 NiOverride 콜백, 액터 격리, 저장 색상 보존, 자원 참조 해제, 동시 생성 취소를 검사했습니다. 실제 제품 함수와 가짜 엔진·GPU 소유권을 사용한 호스트 테스트이며 인게임·실제 GPU 메모리 실측은 아닙니다.

v1.6.7 대비 런타임 ZIP은 SFSCore.dll만 변경합니다. 기존 설정·키트·세이브·선택형 패치를 유지하세요. 지원 게임 버전, RaceMenu 분기, DAVE/DAV/네이티브 소유권, API v1과 기존 export는 그대로입니다. 선행 모드, 폴링, 전체 액터 탐색, 강제 3D 재생성, 실제 장비 조작을 추가하지 않았습니다.

인게임 테스트는 하지 않았습니다. 이번 릴리즈는 v1.6.7 게시 후 확인한 자원 수명 정리 누락 두 건의 수정이며 모든 누수·회귀 또는 별도 제보된 SkyUI 열기 지연의 완전 해소를 주장하지 않습니다.
