# Skyrim Fitting System v1.7.8 SE-AE

## 변경 사항

- SexLab 장면 중 RaceMenu의 뒤늦은 전체 재계산으로 등록 하이힐 높이가 다시 적용되는 경로를 보완했습니다. 기존 하이힐 제거 옵션과 실제 발 장비 탈의 상태를 반영합니다.
- SFS UI를 열었을 때 캐릭터·배경이 흐려지는 현상을 줄이도록 기본 게임과 ENB의 심도 효과를 일시 억제합니다. UI를 닫으면 원래 동작으로 돌아가며, ENB 프리셋에 임시 값이 저장되지 않도록 처리했습니다.
- 하이힐 보정 대기·실패 상태의 불필요한 반복 검사와 안정된 장면의 임시 메모리 할당을 줄였습니다. 안정 상태에서는 추가 인벤토리 조회·Papyrus 호출·높이 재계산을 하지 않습니다.
- 액터 언로드·세이브 전환 시 노드 참조와 예약 작업 정리를 보완해, 이전 작업이 다음 장면의 높이 감시를 막지 않도록 했습니다.
- 기존 바디모프·숨김·탈의/재착의·염색·native/DAV/DAVE 경로를 유지합니다. 새 필수 선행 모드는 없으며 설정·키트·세이브와 기존 선택 패치는 그대로 사용할 수 있습니다.

## 업데이트

전체 패키지를 설치하고 기존 설정·키트·세이브를 유지하세요. 런타임 파일은
SFSCore.dll만 변경됩니다. 필수 선행 모드·지원 게임 버전·스크립트·보조 ESL·
공개 API·저장 형식은 그대로입니다. ENB는 선택 사항이며, 독립적인 ReShade
효과는 이번 블러 제어 범위에 포함되지 않습니다.

선택형 OStim·OStim Standalone 패치는 1.0.0을 유지합니다. 환경에 맞는 하나만
설치하며 이미 설치한 패치는 다시 설치할 필요가 없습니다.

## 검증 범위

SE/AE 전용 DLL 빌드, 회귀 실행 파일 45개와 소스 경계 검사를 통과했습니다.
기록용 대체 경계로 하이힐 노드 검사 3,336회, 구형/신형 RaceMenu 경로,
지연 재계산·장면 옵션·다수 참여자·오래된 작업 취소·반복 언로드/리셋과
기본 게임/ENB의 UI 열기·닫기 복원을 검사했습니다.

SFS가 하이힐 높이를 관리하는 장면 참여자만 감시합니다. 안정된 소규모 장면의
검사 본문에는 임시 목록 할당이 없지만, 작업 예약과 수명 확인 비용은 남습니다.
전체 액터 또는 인벤토리의 주기적 순회는 추가하지 않았습니다.

인게임 FPS 실측이나 제보자의 정확한 애니메이션 구성 재현을 뜻하지 않습니다.
외부 모드의 임의 회전·스케일 조합과 모든 과거 RaceMenu 바이너리를 개별 검증한
것은 아닙니다. [구현 및 상세 점검](HIGH-HEEL-RESCAN-AND-MENU-DOF.md)을 참고하세요.
