# Skyrim Fitting System v1.5.0

## 피팅 염색

- 작업대 기본·조건 영역의 모든 등록 외형 카드에 피팅 염색을 추가했습니다.
  전용 염색 동작이나 카드 우클릭 메뉴에서 열 수 있습니다.
- 팝업은 해당 등록 ARMO에 속한 렌더 외형 조각만 표시합니다. 조각을
  선택하면 액터에서 잠시 점멸해 적용 대상을 확인할 수 있으며, 원본 색상
  복원은 그 조각의 저장 염색을 삭제합니다.
- 염색은 액터 FormID → 등록 외형 ARMO → 정확한 렌더 조각 식별자로
  저장합니다. 같은 메시·diffuse를 쓰는 다른 액터나 다른 등록 외형에는
  번지지 않으며, 정확한 일치가 없거나 둘 이상이면 추측하지 않고
  안전하게 건너뜁니다.
- RGB 염색은 geometry 전용 GPU 텍스처와 그리기 범위가 제한된 교체로
  처리합니다. 원본 DDS/NIF·셰이더 머티리얼·실제 ARMO·인벤토리·키워드·
  장착 상태·작업대 행·조건·키트는 수정하지 않습니다.
- 저장 색상은 세이브 로드나 액터 3D 갱신 뒤에도 같은 액터·등록 외형·
  정확한 조각에만 복원됩니다. 모드 설정 가상토큰·바닐라 슬롯 자동 연동·
  직접 슬롯 편집·외부 탈의/재착의 상태와 DAVE/DAV/native 표시 경로는
  서로 독립적으로 유지됩니다.

## Helmet Toggle 2 호환

- 별도 Helmet Toggle 2 PEX 패치를 없애고 SFSCore 본체 내장 연동으로
  교체했습니다. SFS는 HT2의 정확한 플레이어 상태 전역값과 액터별
  NPC·팔로워 주문 전환만 관찰하며 HT2 스크립트·호출·실제 장비·DAVE
  변형을 교체하거나 수정하지 않습니다.
- HT2의 중복 제거 뒤 남은 배열 위치가 아니라 각 실제 투구 ARMO의 전체
  슬롯 마스크를 읽어 SFS 표시 전환을 계산합니다.
- HT2가 실제 투구 메시를 DAVE 숨김 변형으로 바꿔도 착용 중인 실제
  31+42 투구의 Skyrim worn-mask에는 31 Hair가 남아 원래 머리카락까지
  가릴 수 있었습니다. 이제 정확한 액터별 HT2 숨김 상태일 때만 스키닝
  worn-mask의 실제 31번을 해제해 대머리 현상을 막습니다. 실제 ARMO,
  인벤토리, 키워드, HT2 호출과 DAVE 변형은 바꾸지 않습니다.
- 순수 등록 외형 31번은 계속 HT2로 억제하지 않습니다. 표시 중인 등록
  31번 가발은 Hair 점유를 유지하고, 등록 31+42 카드는 42번을 통해
  계속 HT2 상태를 따릅니다.
- 플레이어·팔로워·NPC 전환은 액터별로 유지하며 주기적 폴링이나 주변
  액터 스캔을 사용하지 않습니다. 로드되지 않은 NPC는 상태만 기록하고
  해당 액터의 3D가 다시 만들어질 때 반영합니다. 모드 설정 슬롯 연동,
  바닐라 슬롯 자동 연동, 직접 슬롯 편집, 수동 눈 버튼, 외부 탈의·재착의와
  DAVE/DAV/native 표시 경로의 기존 동작은 변경하지 않았습니다. 모드 설정
  연동의 머리 슬롯 가상토큰과 탈의·재착의 트랜잭션도 그대로 유지합니다.

SFS 본체를 v1.5.0으로 다시 빌드했습니다. 기존의 모든 **SFS Helmet
Toggle 2 호환 패치**는 완전히 삭제하고 Helmet Toggle 2 본체만 정상
설치하십시오. 별도 SFS 패치는 필요하지 않습니다.
