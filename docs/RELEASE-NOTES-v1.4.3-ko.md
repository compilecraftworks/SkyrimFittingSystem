# Skyrim Fitting System v1.4.3

## 내장 키트 생성기

- 키트 생성기는 `SFSCore.dll`에 내장되어 있습니다. 별도 생성기 DLL이나 모드 폴더가 필요하지 않습니다.
- 의상 ESP 선택, 스캔, 후보 생성, 검색·정렬, 이름 변경, 후보 조각 교체·삭제, 다중 합치기와 키트 생성을 인게임에서 처리합니다.
- 선택 후보는 캐릭터와 작업대의 등록 외형 열에 읽기 전용으로 미리 표시됩니다. 저장된 작업대 행, 인벤토리와 실제 장비는 바꾸지 않습니다.
- 생성기 미리보기에서만 보호 슬롯과 SOS/TNG 성기 장비 후보를 빠짐없이 표시합니다. 일반 등록·적용·저장·장비·의상·키트·탈의 연동 제한에는 이 예외가 적용되지 않습니다.
- 여러 ESP를 CPU·메모리 여유 범위 안에서 병렬 스캔하고, 단일 ESP에는 사용 가능한 작업 예산을 집중합니다. 한 프로필의 멀티슬롯 조합을 푸는 큰 DP 상태도 같은 안전 예산 안에서 병렬 처리하며, 진행률은 완료량만 누적해 표시하므로 바가 뒤로 움직이지 않습니다.
- 하나의 멀티슬롯 조각 때문에 서로 겹치지 않는 슬롯까지 큰 조합 계산에 포함되던 경우를 분리했습니다. 독립 슬롯은 즉시 확정하고 실제로 겹치는 슬롯 묶음만 최적 조합을 계산하므로 결과 규칙을 유지하면서 대형 프로필 스캔을 크게 단축합니다.
- 결과와 후보군 목록은 클릭 단일 선택, `Ctrl+좌클릭` 다중 선택으로 통일했습니다. 후보 이름 클릭은 선택과 미리보기만 바꾸고 별도 편집 버튼만 편집 화면을 엽니다. 두 목록의 고정 동작 열은 UI가 좁아져도 후보군 수와 편집 버튼이 잘리지 않습니다.
- 같은 색상 이름이 반복되는 후보에는 실제로 다른 의상 조각 이름과 번호를 덧붙여 구분합니다.
- 공통 이름 루트와 실제 슬롯 구성을 함께 판정해, 부위 명칭이 알려지지 않은 의상도 상의·하의·신발처럼 서로 보완되는 조각이면 같은 키트로 묶습니다. 컬렉션·시리즈 번호는 키트 식별자로 보존합니다.
- 서로 다른 ESP에 이름만 번역되어 중복 수록된 의상은 이름·NIF 모델 경로·슬롯 구성을 비교해 하나만 남기며, 슬롯 수와 아이템 수가 더 완전한 쪽을 우선합니다.
- 최초 후보는 고유 슬롯 수가 가장 많고 기본형에 가까운 조합을 우선 선택합니다.
- 알려진 의상 팩은 제공된 의상 목록을 우선 기준으로 같은 세트 조각을 묶고, 목록에 없는 팩은 기존의 이름·슬롯·모델 경로 규칙으로 처리합니다. 서로 다른 ESP의 중복 의상은 실제 NIF 모델 경로와 슬롯 구성이 충분히 겹칠 때만 더 완전한 쪽으로 정리합니다.
- 결과 목록의 `항목 삭제`는 Ctrl+좌클릭으로 고른 모든 항목을 정확히 삭제합니다. 선택되지 않은 결과가 삭제되거나 여러 선택 중 하나만 삭제되는 문제를 수정했습니다.

## UI와 작업대

- 키트 탭의 우클릭 메뉴에 **이름 변경**을 추가했습니다. 사용자 키트 JSON의 키트 이름만 안전하게 바꾸며 파일 경로, 조각 구성과 저장된 레이아웃은 유지합니다. 읽기 전용 외부 키트는 변경할 수 없습니다.
- 탭 순서를 `장비 → 의상 → 조건 → 키트 → 키트 생성기 → 옵션`으로 정리했습니다. UI는 기존처럼 키트 탭에서 열립니다.
- 키트 목록의 기존 키보드·게임패드 조작을 유지했습니다. 미리보기는 Skyrim의 `Jump`, 적용은 `Activate`에 매핑된 키 또는 버튼을 따르므로 사용자 재매핑도 반영됩니다.
- 전투 진입·종료와 조건 상태 변화가 UI 재진입이나 세이브 로드 없이 적용되도록 조건 갱신 경로를 보완했습니다. 전투 이벤트는 해당 액터만 즉시 갱신하고, 다른 조건은 등록된 액터·조건의 상태가 실제로 바뀐 경우에만 액터별 표시 갱신을 요청합니다.
- 작업대 기본 영역의 실제 장비·등록 외형 헤더와 조건 영역의 조건 설정·동작 설정 헤더에 정렬을 추가했습니다.
- 멀티슬롯 카드는 하나의 묶음으로 유지하고 빈 실제 장비·등록 외형 행도 전체 정렬에 포함합니다. 조건 영역은 같은 조건 그룹을 분리하지 않으며, 빈 동작 셀은 그룹의 슬롯 정렬값을 왜곡하지 않습니다. 저장 데이터와 실제 행 순서는 변경하지 않습니다.
- 옵션에 `UI 열 때 캐릭터 위치`의 `사용 안 함 / 왼쪽 / 오른쪽`을 추가했습니다. Show Player In Menus의 플레이어 회전·오프셋 공식을 따르고 SmoothCam이 활성화된 경우 공개 API로 메뉴 동안만 카메라 제어권을 요청합니다. 창을 다시 열 때도 저장된 위치를 재적용하며, 좌우 배치별 정면 방향 보정, 캐릭터 영역 우클릭 드래그 회전과 종료 시 원상 복원을 유지합니다. 1인칭은 변경하지 않습니다.
