# Skyrim Fitting System v1.7.0 SE-AE

## 변경 사항

- 다른 플러그인이 지원되는 5바이트 CALL 위치를 E9 점프로 변경했을 때 착용 슬롯·등록 외형 훅 설치를 건너뛰던 경로를 수정했습니다. SFS 1.6.6 / Skyrim SE 1.5.97 제보처럼 UI는 열리지만 외형 표시·장비 숨김이 작동하지 않는 원인이 될 수 있었습니다. 같은 건너뛰기 경로가 1.6.9에도 남아 있었습니다.
- SE·AE의 등록 외형 부착·착용 슬롯·실제 장비 부착 훅에 액터별 E9 대응을 추가했습니다. SFS 스키닝이 비활성인 액터는 원래 스택·휘발성 레지스터·플래그를 유지해 기존 점프로 넘기고, 활성 액터는 원래 엔진 호출과 SFS 표시 정책을 사용합니다.
- 기존 E8 호출 방식과 외부 모드의 구체 visitor 보호는 유지합니다. IED 설치 시 활성 E9 외형 경로에서 기존 중복 병합·로드 취소 큐로 평가를 요청하며, IED가 없으면 해당 요청을 하지 않습니다.

## 호환 범위

**E9 대체 경로에서는 SFS 스키닝이 활성인 액터에 SFS 표시가 우선됩니다.** 이 액터에서는 기존의 미확인 인라인 코드를 실행하지 않으므로, 같은 액터를 다른 외형 모드도 제어하는 경우 그 모드의 모든 동작까지 보존한다고 보장하지 않습니다. 인라인 점프 대상을 일반 함수처럼 호출하거나 복귀 주소를 추측하지 않으며, 외부 모드의 코드를 수정하지 않습니다. 비활성 액터는 기존 모드의 복귀 경로를 그대로 따릅니다. 지원 게임 버전과 DAVE/DAV/네이티브 백엔드 선택 기준은 변경하지 않았습니다.

1.6.9 대비 런타임 ZIP에서는 SFSCore.dll만 변경됩니다. 소스 ZIP의 라이선스 안내 버전도 갱신했습니다. 스크립트·보조 ESL·번역·설정/세이브 형식·API·RaceMenu 인터페이스·선택형 패치는 변경하지 않았습니다. 실제 장비 조작이나 신규 스캔/폴링·작업 스레드·누적 액터 이력·임시 런타임 진단 코드를 추가하지 않았습니다. 기존 설정·키트·세이브·선택형 패치를 유지하세요.

Wet Function Redux Visual Effect Patch v1.2.0은 Papyrus 스크립트와 README로 구성되며 네이티브 DLL을 포함하지 않습니다. 제보의 E9 훅을 직접 설치하는 패치는 아닙니다. 로그만으로 실제 훅 제공 모드를 특정할 수 없으므로 Wet Function을 확정 원인으로 안내하지 않습니다.

## 검증

수정 전 실제 프로덕션 훅을 사용하는 E9 재현 검사가 실패하는 것을 확인했습니다. 수정 후 SE·AE의 실제 생성 기계어와 visitor 경로를 실행하는 2,600개 사례를 검사합니다. 경로별 128회 활성/비활성·숨김/표시 전환, 등록 외형 부착, 슬롯 결과, 실제 장비 인수, IED 유무, 기존 E8 연결, 휘발성 상태를 의도적으로 변경한 뒤의 E9 스택·레지스터·플래그 보존을 포함합니다.

전체 회귀 검사 28개와 소스 연결 검사가 release·releasedbg에서 통과했습니다. SE/AE 전용 DLL 빌드, 내부 버전 1.7.0.0, 기존 내보내기 이름 16개 유지를 확인했습니다. 자세한 결과와 패키지 검사는 [기술 기록](V1.7.0-INLINE-DETOUR-FIX.md)을 참고하세요. 제보자의 미확인 훅 모드를 사용한 인게임 재현 검증은 하지 않았으며, 모든 모드 조합의 무결함을 보장하는 결과는 아닙니다.
