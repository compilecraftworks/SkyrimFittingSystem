# Skyrim Fitting System v1.6.4

## 변경 사항

- 폼을 참조하는 조건의 인수1은 EditorID를 우선 표시합니다. EditorID가 없거나 해석할 수 없으면 기존 값을 표시하며, 액터·참조 항목은 FormID도 보조 표시합니다. 단순 열람·포커스·동일 항목 확정으로 저장된 플러그인별 식별값을 바꾸지 않습니다. 인수2, 숫자·열거값·변수명은 그대로 유지합니다.
- 섹랩 재착의 OFF처럼 외부 탈의 후 재착의하지 않은 상황에서 수동 외형 표시가 무시되는 문제를 수정했습니다. 저장된 숨김 값은 이미 꺼져 있어도 탈의연동 상태가 외형을 숨기고 있으면, 개별·전체 표시 요청으로 해당 숨김 상태를 해제합니다.
- 재착의 없이 끝나면 외형은 숨겨진 채 유지하며, 사용자 조작이나 기존의 유효한 복구가 있을 때만 표시됩니다. 실제 장비가 재착의되면 기존 자동 외형 복구가 유지됩니다. 실제 장비 착용·해제나 섹랩 설정 판별 코드는 추가하지 않았습니다.
- 수동 조작·삭제로 탈의연동 상태를 해제할 때 대상 액터만 처리하도록 수정했습니다. 다른 액터의 같은 슬롯 외형과 탈의 기록은 유지합니다.
- 탈의연동 캐시 갱신에서 액터의 활성 외형을 슬롯마다 반복 계산하던 작업을 줄였습니다. 한 번 계산한 결과를 32개 바디 슬롯 조회에 재사용합니다.
- 슬롯 우선순위, 다중 슬롯 외형의 식별 정보, 보호·잠금, 직접 매핑과 기존 전체 갱신 범위를 유지합니다. 조건 결과를 오래 보관하거나 갱신 주기를 늦추지 않습니다.
- 바닐라 몸통 키워드 판정에서 SFS 외형 변경이 활성화되지 않은 경우, 불필요한 최종 착용 외형 수집을 생략합니다. 관리 중인 액터의 실제 장비·등록 외형 숨김과 최종 표시 상태에 따른 판정은 유지합니다.
- 염색과 무관한 최상위 렌더 패스의 기록·복원 작업을 줄였습니다. 미리보기가 있을 때만 타이머를 조회합니다. 중첩된 비염색 패스의 색상 전파 방지, 염색 대상의 텍스처 적용·복원과 다른 렌더러의 훅 연결은 유지합니다.
- 32슬롯 조회 결과 동등성, 염색 중첩 패스와 실제 코드 연결을 검사하는 회귀 항목을 추가했습니다.

## 적용 범위

1.3.0 이후 도시 이동 중 버벅임 피드백을 조사하며 발견한 중복 연산을 줄인 수정입니다. 실제 FPS 개선 수치나 모든 제보 환경에서의 해결을 보증하지 않으며, 도시 이동과 실제 D3D 렌더링 비교는 인게임 검증이 필요합니다.

게임·RaceMenu 지원 범위, 설정·세이브 형식과 선택형 호환 패치는 변경하지 않습니다. 바디모프 상태 관리와 DAVE/DAV/네이티브 갱신 분기도 그대로 유지합니다. 기존 설정과 프리셋을 보존하십시오.

## 로컬 검증 (2026-09-12)

- SE/AE 전용 releasedbg 빌드 성공. DLL 파일·제품 버전은 1.6.4.0입니다.
- 바디모프 추적, 탈의연동 정책, 외부 스킨 훅 분기 등을 포함한 빠른 회귀 테스트 17개와 실제 코드 연결 검사를 모두 통과했습니다.
- 슬롯 조회는 빈 목록, 단일·다중 슬롯, 겹치는 슬롯과 생성된 입력을 기존 개별 조회 방식과 비교했습니다. 결과 동등성 검사이며 프레임 시간 측정은 아닙니다.
- 염색 대상 목록의 동기화 잠금은 유지합니다. 타이머·렌더 패스 기록 비용을 줄인 것이며 모든 조회 비용을 없앤 것은 아닙니다. 장기 보관 외형 캐시도 추가하지 않았습니다.
- 대체 후 사용처가 없어진 내부 단일 슬롯 외형 식별 API와 출력 인수는 전체 소스·외부 소비자 참조 확인 후 제거했습니다.
- 수동 표시 검사는 실제 setter·탈의 상태 해제·재착의 완료 함수를 가짜 엔진 경계와 함께 컴파일합니다. 재착의 없음·실제/부분 재착의, 개별·전체 방식 조작, 플레이어/NPC 격리, 개별 외형 기록, 오래된 콜백, DD 숨김 해제와 128회 반복을 검사합니다. 실제 섹랩 인게임 테스트를 대신하지는 않습니다.
- 실제 폼 조회 코드와 ImGui 테스트로 EditorID 표시, 저장값 보존, 포커스·Enter·포커스 이동, 목록 로딩, FormID 직접 입력, 첫 클릭 선택, 긴 표시값과 대체 표시를 검사했습니다. 표시를 위해 전체 게임 레코드를 탐색하지 않으며, 인게임 화면 확인은 남아 있습니다.
