# Skyrim Fitting System v1.7.2 SE-AE

## 변경 사항

- 등록 하이힐의 HH_OFFSET 정보를 실제 부착 전에 삭제해 높이를 잃던 경로를 수정했습니다.
  일시적 분리·재부착은 기존 제한된 재시도 안에서 기다리고, 제거된 노드는 정리합니다.
  새로 관찰한 신발 기록을 이전 작업이 삭제하거나 언로드 후 이전 높이를 적용하지 않도록 했습니다.
  실제 장비는 조작하지 않으며 공개/구형 NiOverride 경로와 다른 모드의 높이 보정은 유지합니다.
- 숨김 슬롯·스키닝 마스크 조회 하나 안에서 착용 장비를 중복 수집하지 않도록 개선했습니다.
  몸통/최종 외형 조회도 같은 요청에서 계산한 표시 목록을 재사용해 중복 생성을 줄였습니다.
  실행용 조건 조회는 UI 설명 데이터를 복사하지 않고 같은 조건 객체를 사용합니다.
  스크립트 연결 검사의 캐시 충돌도 줄였으며 보관 한도 128개, 최초 연결·늦은 등록·P+ 재시도는 유지합니다.
  누드 판정과 탈의/재착의 판정은 유지하며 BCNG의 결과를 내부 판정에 가져오지 않습니다.
- 장비·의상·키트의 '즐겨찾기만'을 각각 독립적으로 저장합니다. 한 탭에서 바꿔도
  다른 탭의 체크는 바뀌지 않습니다. 이전 공통 설정은 한 번 이어받으며,
  필터 변경 시 목록 포커스만 이동하고 작업대 미리보기는 유지합니다.
- 커뮤니티 허브의 같은 의상에 속한 색상·길이·번호별 변형을 하나의 키트 그룹 안의
  후보들로 묶습니다. 각 원래 구성은 그대로 유지하며 서로 다른 변형의 부품이나 다른
  플러그인을 섞지 않습니다. Birth Lingerie 같은 번호별 세트도 같은 번호끼리 유지합니다.
  설치 자료의 32개 장비는 한 그룹·16개 짝맞춤 후보로 확인했습니다.
  ESP를 다시 분석하면 반영되며, 이미 저장한 키트 파일은 자동 변경하지 않습니다.
- 키트 생성 결과에 체크박스를 추가했습니다. 체크된 항목만 생성·합치기·삭제하며,
  후보가 하나뿐인 키트도 목록에 표시합니다. Ctrl로 개별 행, Shift로 정렬된 범위를
  선택한 뒤 체크박스 하나로 함께 체크/해제할 수 있습니다. 행 더블클릭은 기존처럼
  하위 후보 목록을 열고, 체크박스 클릭은 미리보기나 하위 진입을 실행하지 않습니다.
  항목 삭제 옆에 전체 선택·선택 해제를 추가했습니다. 전체 선택은 현재 보이는 목록,
  선택 해제는 숨겨진 항목까지 포함한 전체 체크에 적용됩니다. 숨겨진 체크 수를 표시합니다.
- 키트 생성기 결과의 미리보기 체크박스 앞과 ESP 목록에 키트 탭과 동일한 체형 필터를
  추가했습니다. 두 화면은 각각 전체가 기본이며 목록만 필터링합니다. ESP는 일치하는
  장비가 하나 이상인 플러그인, 결과는 선택한 후보의 체형 기준입니다. 필터로 가려져도
  체크와 기존 미리보기는 유지하며 생성 후보 구성·적용에는 체형 제한을 추가하지 않습니다.
- SFS 목록 탐색에 사용한 키가 이후 전달되는 다른 모드의 단축키 이벤트에 중복 전달되지 않도록
  수정했습니다. 창을 닫으면 새 키 입력은 정상 전달하고, SFS에서 누르기 시작한 키의 남은
  유지·해제 이벤트만 마무리합니다.
- 키트 생성기 ESP 목록에서 Ctrl+클릭 개별 선택·해제, Shift+클릭 범위 선택·해제를 지원합니다.
  범위와 전체 선택/해제는 정렬·검색 후 보이는 목록 기준입니다. 착용 모델이 있는 플러그인만
  보는 선택형 필터를 추가했으며 액세서리 전용 모드와 숨겨진 선택은 보존합니다.
  빨간색 그룹화 경고에는 최대 폭·문단 구분·자동 줄바꿈을 적용한 판정 기준 툴팁을
  추가했으며 스캔을 차단하지 않습니다.
- 커뮤니티 키트 커스텀 패치 4의 누적 기능을 공식 소스와 전체 설치 패키지에 통합했습니다.
- 장비·의상·키트 탭 왼쪽 목록의 즐겨찾기/미리보기 앞에 체형 필터를 추가했습니다.
  전체 / CBBE·3BA / UNP·BHUNP / UBE / HIMBO / SAM / 바닐라를 선택하며,
  세 탭이 선택을 공유하고 저장합니다. 기본값은 전체이고 기존 캐릭터 체형 자동 필터를 대체합니다.
  CBBE·3BA·단독 3BBB와 복합 표기도 판정합니다.
- **체형 필터는 목록에 뜨는 항목만 거릅니다.** 변경하면 정렬된 첫 항목으로 키보드·게임패드
  포커스와 스크롤을 이동합니다. 이 이동만으로 적용·미리보기를 실행하지 않으며 기존 미리보기와
  등록 외형은 유지합니다. 빈 목록에는 이전 항목의 적용 대상이 남지 않습니다.
  작업대 적용이나 미리보기를 체형으로 제한하지 않습니다.
- 키트 묶음은 Modex 커뮤니티 → ADD 사진 참조 → Excel → 범용 추론 순으로 판단합니다.
  커뮤니티의 명시적 구성은 후보 내부에 보존하고, ADD 키트 이름 542개와 검토된 디자인별 예외를 유지합니다.
  사진 순번을 장비 디자인 번호로 임의 해석하지 않습니다.
- 번역명이나 부위명이 달라 갈라진 의상을 내부 식별자·모델 폴더·보완 슬롯 근거로 연결하고,
  기존 묶음의 귀걸이·후드 등 부속품을 보존합니다. 제작자·공용 신발·남성 대체 모델만
  같다는 이유로 다른 의상을 합치지 않습니다.
- 같은 의상의 색상·스타일 후보를 가능한 한 통일하고 실제 30~61 슬롯 중복을 방지합니다.
  5개 이상 변형, 여러 선택 축과 몸통 스타일 대표를 256개 후보 한도 안에서 보존하며,
  긴 분석 중 취소 요청도 처리합니다.

## 업데이트 안내

본체 전체 설치 패키지입니다. 이전 커뮤니티 키트 커스텀 패치 1~4가 새 DLL·번역을
덮어쓰지 않도록 별도 패치는 비활성화/제거하세요. 기존 설정·키트·세이브는 유지합니다.
Wet Function·Dynamic Footprints·Modesty 선택형 호환 패치는 변경하지 않았습니다.

선행 모드·게임 지원 범위·API ABI 변경은 없습니다. 스키닝 조회·실행 조건·스크립트 연결 검사 비용은
개선하지만 표시/탈의 정책과 IED 라우팅은 유지합니다. 하이힐 부착 기록 수명은 수정했으며,
바디모프 정점 적용과 염색 구현은 변경하지 않습니다.
참조표는 본체에 포함되어 실행 시 Excel·사진·Modex·Python이
필요하지 않습니다. 해당 장비를 사용하려면 장비 모드 자체는 설치되어 있어야 합니다.

## 확인 범위와 한계

SkyUI 제보 환경의 약 4초 지연은 실측하지 않았으며 완전 해결로 확정하지 않습니다.
여러 조회 사이의 표시 결과 캐시는 아직 적용하지 않았습니다. [조회 비용 검증](SKYUI-QUERY-COST-FIX-2026-09-29.md).
하이힐은 수정 전 실패/수정 후 통과를 소스 기반 검사에서 확인했지만 제보자의 게임 환경은 미검증입니다.
[하이힐 수정·검증 범위](HH-PENDING-ATTACHMENT-FIX-2026-09-29.md).

체형 분류는 이름·플러그인·모델 정보 기반이며 실제 메시의 호환성을 보장하는 판정은 아닙니다.
혼합 묶음은 여러 계열에 나타날 수 있고 바닐라는 명시적 체형 정보가 없는 카탈로그 대체 분류도 포함합니다.
사진을 그대로 재현하는 기능은 아니며, 별도 ARMO가 없는 BodySlide 차이는 구분할 수 없습니다.
후보가 256개를 넘으면 모든 조합을 나열하지 않습니다.

실자료 검사는 오프라인 정의 레코드 기준이며 전체 로드오더 오버라이드를 적용한 결과는 아닙니다.
게임 내 UI·미리보기·적용·저장은 미검증입니다. 빌드·검사 결과는
[통합 기록](V1.7.2-KIT-INTEGRATION.md)에 별도로 기록합니다.
키 상태를 직접 조회하거나 SFS 입력 훅보다 먼저 처리하는 다른 모드의 단축키까지 차단된다는
보장은 아니며, 해당 모드는 게임 내 확인이 필요합니다.
