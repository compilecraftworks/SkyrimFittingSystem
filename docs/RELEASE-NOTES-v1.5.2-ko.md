# Skyrim Fitting System v1.5.2

## 등록 외형 잠금

- 등록 외형 카드의 우클릭 메뉴에서 외형을 잠그거나 잠금 해제할 수 있습니다.
  이름 뒤에 작은 자물쇠 아이콘을 표시하며 액터별 잠금 상태는 SKSE 코세이브에
  저장합니다.
- 잠긴 외형은 장비·의상·조건·키트·키트 생성기 결과를 미리 보거나 적용할 때
  그대로 유지됩니다. 새 멀티슬롯 외형의 표시 슬롯 하나라도 잠긴 외형과
  겹치면 해당 카드를 통째로 제외합니다.
- 모드 설정·바닐라·직접 편집 탈의 연동과 DD Hider·Helmet Toggle 2의 자동
  억제로 잠긴 외형을 숨기지 않습니다. 수동 눈 상태와 조건 결과는 기존
  동작을 유지합니다.

## 등록 외형 하이힐

- 등록 외형 메시의 `HH_OFFSET` 값을 RaceMenu 공개 NiTransform 인터페이스로
  플레이어·NPC·팔로워에게 동기화합니다.
- DAVE·DAV·native 표시 갱신과 늦게 완료되는 DAVE 부착 콜백을 액터별 이벤트로
  처리합니다. 주변 액터를 스캔하거나 프록시 장비를 착용시키지 않고 실제
  장비도 변경하지 않습니다.
- SFS의 임시 변환 부트스트랩만 제거하며 실제 착용한 하이힐에 대한 RaceMenu
  처리는 보존합니다.

## 입력·염색·배포

- 작업대 키트 목록을 기존 방향키와 함께 W/S로 탐색할 수 있습니다. 실제 SFS
  텍스트 입력란이 키보드 포커스와 편집 커서를 가진 동안에는 이 탐색 입력을
  처리하지 않습니다.
- 피팅 염색 목록에서 CBBE/3BA/3BBB, UNP/BHUNP, UBE, HIMBO, SAM 및 바닐라
  바디 계열의 기본 몸체·헬퍼 지오메트리를 제외하고 실제 의상 조각만
  유지합니다.
- 런타임 ZIP과 MO2 배포에서 PDB를 제외합니다. 디버그 심볼은 필요할 때 쓸 수
  있도록 로컬 빌드 폴더에만 남깁니다.

## 호환 경계

- 액터 소유권, DAVE/DAV/native 분리, BodyMorph·염색 상태, 모드 설정·바닐라·
  직접 편집 탈의 연동, DD, Pama, Grid Inventory, OAR, Helmet Toggle 2 상태는
  새 잠금·하이힐 상태와 분리해 유지합니다.
- IED 호환 `VisitWornItems` 체인과 실제 인벤토리·장비 의미는 변경하지
  않았습니다.
