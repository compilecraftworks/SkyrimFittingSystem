# Skyrim Fitting System v1.7.6 SE-AE

## 변경 사항

- SFS 1.7.6 이상용 OStim·OStim Standalone 탈의 연동 패치 1.0.0을 정식으로 추가했습니다.
- 모드 설정 연동·바닐라 슬롯 연동과 직접 편집의 두 기준을 연결합니다. 슬롯 보호·NoStrip·각 프레임워크의 가발 설정을 유지합니다.
- 전체·부분·애니메이션 재착의를 액터·장면별 소유권으로 연결합니다. 실제 장비와 OStim 착용 장비 배열은 OStim이 계속 관리합니다.
- 바닐라 자동 가발 연동을 LongHair 41번으로 조정했습니다. 31+42 투구 처리와 사용자가 저장한 명시적 매핑은 변경하지 않습니다.
- 표시 중인 머리 덮는 투구에 따라 순수 등록 41번 가발을 숨기고, 투구를 숨기거나 벗으면 복원합니다. Helmet Toggle 2에도 적용하며 수동 숨김·잠긴 외형은 보존합니다.
- 기존 native·DAV·DAVE 렌더, 바디모프·하이힐·염색·조건·IED·공개 API 동작을 유지합니다. 주기적 액터·인벤토리 스캔이나 새 필수 선행 모드는 추가하지 않았습니다.

## 업데이트와 선택 패치

SFS 전체 패키지를 설치하고 기존 설정·키트·세이브를 유지하세요. 필수 선행 모드와
지원 게임 버전 목록은 그대로이며 OStim은 SFS의 필수 선행이 아닙니다.
본체 런타임에서는 SFSCore.dll과 제3자 고지만 변경합니다.
기존 ESL·PEX 스크립트·나머지 런타임 파일은 변경하지 않습니다.

OStim 연동이 필요하면 SFS 1.7.6 이상과 해당 프레임워크 뒤에 아래 중 하나만 설치하세요.

- **SFS - OStim Strip Link Patch:** 구형 OStim의 Quest 기반 OUndress용.
- **SFS - OStim Standalone Strip Link Patch:** Standalone의 정적 OUndress용.

두 패치의 버전은 각각 1.0.0입니다. MO2/Vortex에서 패치의 OUndress.pex가
충돌에서 이겨야 합니다. 적용·제거 후 게임이나 세이브를 다시 로드하세요.
OStim은 UsePapyrusUndressing을 게임 로드당 한 번 읽습니다.
다른 모드도 OUndress를 바꾸면 두 개를 동시에 설치하지 말고 변경 사항을 병합해야 합니다.
OStim DLL·새 ESP·퀘스트·컴파일용 선언은 설치하지 않습니다.
패치에는 설치 안내·라이선스·수정 소스·SFSOStimBridge가 포함됩니다.
[패치 README](../compat/OStimSfsPatch/README.txt)를 참고하세요.

41번 가발 연결은 자동 외형 매핑만 바꿉니다. 실제 장비 슬롯 마스크·31+42 투구 처리·
명시적으로 저장한 31번 매핑·연동 안 함은 그대로입니다. 순수 등록 41번 가발의
투구 가림도 최종 표시 상태에만 적용하며 저장 행이나 수동 숨김은 수정하지 않습니다.

## 검증 범위

SE/AE 전용 본체 빌드·두 Papyrus 패치·회귀 실행 파일 42개와 소스 경계 검사를
통과했습니다. 공개 API·Papyrus 호출 규약을 고정된 업스트림 소스와 대조했습니다.
실제 생산 코드 기반 검사로 NoStrip·가발·매핑·보호·소유권·부분 재착의·저장된
장면 키·트랜잭션 번호 재할당·지연 재착의·제외된 NPC·128회 장면 전환을 검증했습니다.
장면 어댑터는 정확한 int32 ID·패치 활성/부재·멤버십·중복 콜백 등록 방지를 확인합니다.
바닐라 가발 연동은 3,367개 검사와 128회 전환을 추가했고, 롱헤어 가림은
플레이어/NPC·투구 표시/숨김·잠금·혼합 슬롯 제외를 검사합니다.

엔진 경계는 기록용 대체 객체를 쓰는 소스·호스트 검사입니다. 실제 인게임 장면·
애니메이션 타이밍·장면 중 세이브 로드·모든 외부 바이너리 조합을 각각 실행했다는
뜻은 아닙니다. 패키지는 테스트 빌드가 아닌 정식판으로 게시하되 이 검증 범위를
분명히 구분합니다.
