# Skyrim Fitting System v1.4.2

## 선택형 키트 생성기 연동

- 별도 배포되는 SFS Kit Generator 옵션을 위한 버전형 런타임 브리지를 추가했습니다.
- 호환되는 옵션 DLL이 이미 로드된 경우에만 옵션 탭 뒤에 키트 생성기 탭을 표시합니다.
- 생성 후보를 선택하면 등록 외형 후보가 작업대에도 읽기 전용으로 표시됩니다. 저장된 작업대 행·인벤토리·실제 장비는 변경하지 않습니다.
- 작업대가 불완전하게 보이지 않도록 임시 생성기 미리보기에서는 보호 슬롯과 SOS/TNG 성기 장비 후보도 표시합니다. 일반 등록·적용·저장·표시 필터는 그대로이며, 같은 Skyrim 표시 슬롯을 점유하는 조각은 기존 엔진 충돌 규칙을 따릅니다.
- 탭 이탈·생성 취소·SFS 종료 시 기존 미리보기 정리 경로로 생성 후보 미리보기를 해제합니다.
- SFSCore는 옵션 DLL을 정적으로 링크하거나 강제로 불러오지 않습니다. 옵션을 설치하지 않은 본체의 UI와 동작은 기존과 같습니다.

## 업데이트

이전 SFS 모드 폴더를 완전히 삭제한 뒤 v1.4.2 ZIP을 새로 설치하고 `SkyrimFittingSystem-VirtualTokens.esl`을 활성화하십시오. SFS Kit Generator는 필요할 때만 별도로 설치하며, 생성기 패키지로 `SFSCore.dll`을 교체하지 않습니다.
