Skyrim Fitting System v1.6.5 SE-AE
- 최종 표시 실제 장비·등록 외형, 유효 슬롯, 몸통 가림 정보와 액터별 수명 알림을 제공하는 읽기 전용 Rendered Outfit API v1을 추가했습니다.
- 검증된 구형·신형 런타임용 IED 1.7.4의 BipedSlot 조건 연동을 내장했습니다. 지원되는 장비·노드 조건이 SFS 최종 표시 상태를 참조하며, 별도 SFS 패치나 IED 파일 교체는 필요 없습니다.
- IED 미설치 시 연동 훅·알림 구독·IED 재평가 작업이 없습니다. 다른 IED 조건 계열과 미지원 바이너리는 원래 IED 동작을 유지합니다.
- 기존 헬겐 스키닝 방문자 충돌 방어를 유지하고 언로드·삭제·로드 취소 회귀 검사를 추가했습니다. 액터별 재평가 요청은 중복을 합치고 장면 변경만으로 반복되지 않습니다.
- LT + RS 좌우 회전과 타이틀 X 버튼 옆 우측 정렬 회전 안내를 추가했습니다.
- 키보드·게임패드 취소키 재지정을 따릅니다. 팝업·편집기를 먼저 닫고, 없으면 SFS 본창을 닫습니다.
- 최초 캐릭터 위치는 왼쪽, 게임 일시정지는 체크 해제가 기본입니다. 기존 저장 설정은 유지합니다.
- 회귀 테스트 20개를 모두 통과했습니다. 게임·RaceMenu 지원, 바디모프 관리, DAVE/DAV/네이티브 분기와 선택형 패치 버전은 그대로입니다.
- 실제 헬겐·게임패드 테스트와 프레임 시간 비교는 남아 있으며, CTD 없음이나 FPS 개선을 보증하지 않습니다.
