# Skyrim Fitting System v1.5.5

- 교체 미리보기와 임시 숨김 전환 중 등록 외형의 모프 추적이 끊겨 실시간
  BodyMorph·OBody 갱신을 놓치는 경로를 수정했습니다.
- 미리보기의 최초 모프 적용과 이후 실시간 갱신을 분리해 최초 적용이
  중복되지 않도록 했습니다.
- 늦게 부착되는 외형과 표시 복원 시 놓친 갱신을 액터별로 복구합니다.
  복구 작업은 제한된 횟수만 수행하고 오래된 예약 작업은 무효화합니다.
- 외형 노드 검사에서 모프 잠금과 작업대 잠금을 중첩 획득하던 부분을
  제거했습니다.
- 실제 추적 함수로 직접·지연 갱신, 플레이어/NPC 격리, 1·3인칭,
  노드 재사용·늦은 부착·최초 적용 분리를 검증하는 회귀 테스트를 추가했습니다.

바디 호환 목록 옵션, 탈의·재착의 resolver, 외형 잠금, 염색, 실제 장비,
렌더 backend 선택과 RaceMenu ABI 프로필은 변경하지 않았습니다.
별도 패치는 필요하지 않습니다. 확인된 추적 수명주기 문제를 수정한 것으로,
바디 필터 체크박스 자체가 모든 제보의 원인이라고 단정하지 않습니다.

자동 테스트가 DAVE·DAV·native 인게임 검증을 대체하지는 않습니다.
[회귀 범위와 인게임 확인 경로](BodyMorph-v1.5.5-Regression-Checks.md)를 참고하세요.
