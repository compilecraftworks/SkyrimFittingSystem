Place Skyrim Fitting System kit JSON files in this folder.

Virtual game path:
Data/Interface/SkyrimFittingSystem/user/kits

MO2 mod folder path (do not add another Data folder):
Interface/SkyrimFittingSystem/user/kits

Kits created in-game are saved here. Fitting Kit Generator output can also be
copied here. UTF-8 Korean, Chinese, and other Unicode names are supported.
Invalid or unreadable JSON files are skipped instead of being loaded.
